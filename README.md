# FitTrack - Aplikasi Jadwal & Latihan Olahraga

Aplikasi web modern untuk perencanaan jadwal olahraga mingguan, panduan gerakan barbel dan bodyweight, serta pelacak target Dream Body.

## Cara Menjalankan di Komputer / Laptop:

1. Pastikan Node.js sudah terinstal di komputer Anda (download di https://nodejs.org).
2. Buka terminal atau Command Prompt di dalam folder proyek ini.
3. Jalankan perintah instalasi dependency:
   ```bash
   npm install
   ```
4. Jalankan server development:
   ```bash
   npm run dev
   ```
5. Buka browser dan buka alamat:
   ```
   http://localhost:3000
   ```

## Fitur Utama:
- Jadwal latihan mingguan interaktif (Senin - Minggu)
- Pustaka gerakan barbel & bodyweight dengan tombol pencarian internet instan
- Vision board Dream Body & foto progres transformasi
- Penghitung otomatis BMI dan catatan berat badan
- Penyimpanan persisten lokal (LocalStorage)
